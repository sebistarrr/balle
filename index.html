Chaque animation est doublée d'un script qui en produit la version vidéo ; le lien est sur la page de l'animation. Dix-neuf passent par Manim ; les dix qui manipulent des milliers d'objets à chaque image — la prison, les six reproductions et les trois variantes — passent par Cairo, vingt-quatre fois plus rapide sur ce contenu.

Les trente duels d'éléments sortent tous du codex des éléments : douze fiches — forme, couleur, vie, vitesse, pouvoir — recopiées à l'identique dans chaque affiche.
